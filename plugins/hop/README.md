# hop plugin

git worktree manager「hop」(nuthatch) の使い方 skill を配布する plugin。
Claude Code / Codex の両方から install できる。

- `skills/nuthatch/` — coding agent 向けの hop 運用 skill

## Install

```
# Claude Code
/plugin marketplace add n-seiji/nuthatch
/plugin install hop@nuthatch

# Codex
codex plugin marketplace add n-seiji/nuthatch
codex plugin install hop
```
